# Config Requirements

To run this config, you may need to install some things.
The recommended distribution of Linux to use is Arch Linux.

```bash
sudo pacman -S git base-devel curl unzip wget wl-clipboard xclip ripgrep fd nodejs npm python python-pip rust clang jdk-openjdk dotnet-sdk php zig texlive-meta zathura zathura-pdf-mupdf python-pygments stylua chafa poppler
sudo npm install -g prettier
```

Run both commands in your terminal before opening NeoVim.
